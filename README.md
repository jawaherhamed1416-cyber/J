# مداد الجوهرة – بناء APK ونشر الموقع

## الحصول على APK (بدون تثبيت أي برنامج)
1. أنشئ حساباً مجانياً على github.com ثم مستودعاً جديداً.
2. ارفع كل محتويات هذا المجلد (بما فيها المجلد المخفي .github).
3. افتح تبويب Actions ثم Build APK ثم انتظر نحو 5 دقائق.
4. نزّل tughra-store-apk من أسفل صفحة التشغيل، وانقل app-debug.apk إلى الجوال وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

## الموقع
اسحب مجلد www إلى app.netlify.com/drop أو إلى Cloudflare Pages، فتحصل على رابط يعمل ويُثبَّت على الجوال من المتصفح.
